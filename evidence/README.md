# Evidence

Everything here came from real runs against two unrelated live web apps:
- [ParaBank](https://parabank.parasoft.com/parabank/): Parasoft's public demo bank. We used a demo customer we registered,
  `cua_demo_6955`, with accounts 31437 and 31770, because the shared user `john` was returning server errors.
- [SauceDemo](https://www.saucedemo.com/): a public demo shop built for automation testing.

It is regenerated by `scripts/make_evidence.sh`. The exact commands and their output are in [`transcript.txt`](transcript.txt).

Each run folder has `log.jsonl` (every event, redacted) and screenshots. Replay runs also have `result.json`, the
contract the caller gets. The AI marked `balance` as sensitive, so it is stored as `[sensitive]` on disk while the
caller receives the value. Failed runs add a final screenshot and `a11y.txt`, the page's accessibility snapshot.
Escalations add `intervention.json`, the request routed to a human.

**Replay is plain code by default.** The AI is involved only in recordings, and in replays run with `--ai`.

**ParaBank: read a balance.** The goal was plain English: *"Log in as cua_demo_6955 with {password:secret}, open account
31437 and read its balance"*. The AI chose the inputs `username` and `account_number`.
